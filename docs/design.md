# Проектирование
Интерфейс состоит из панели элементов, рабочей области SVG, панели свойств и панели команд. Модель содержит массивы узлов и потоков, каждый поток ссылается на идентификаторы источника и получателя. Модуль model.js отвечает за операции над моделью, проверку и экспорт; app.js — за взаимодействие с пользователем.
