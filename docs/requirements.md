# Требования
Редактор предназначен для построения базовых моделей бизнес-процессов. Пользователь должен иметь возможность создавать события, задачи и шлюзы, соединять их потоками, перемещать и переименовывать элементы, удалять объекты, проверять структуру, сохранять и загружать диаграммы, экспортировать BPMN XML.
Приложение работает в браузере без серверной базы данных. Данные текущей диаграммы хранятся локально.
