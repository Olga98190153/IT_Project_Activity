# Визуально-графический конструктор BPMN

Проект по дисциплине «Проектная деятельность в ИТ».
Автор: Чеботарева Ольга Михайловна.

## Запуск
Распаковать содержимое архива в каталог C:\xampp\htdocs\IT_Project_Activity, запустить Apache в XAMPP и открыть http://localhost/IT_Project_Activity/. Также можно открыть index.html напрямую.

## Возможности
Начальные и конечные события, задачи, исключительные и параллельные шлюзы, последовательные потоки. Размещение и перемещение элементов, изменение названий, удаление, отмена и повтор действий, локальное автосохранение, импорт и экспорт JSON, экспорт BPMN 2.0 XML с координатами, структурная проверка модели. Редактор предназначен для построения базовых диаграмм, не для исполнения процессов или полной проверки стандарта BPMN.

## Проверка
При наличии Node.js: node --test tests/model.test.js.
